# Storage Converter

## Purpose
Converts storage size from GB to MB, KB, and bytes.

## How to Run
1. Install Python 3.
2. Run the program:

```
python storage_estimator.py
```

## Example
**Input:**
```
Enter storage in GB: 2
```

**Output:**
```
Storage in MB:  2048
Storage in KB:  2097152
Storage in Bytes:  2147483648
```
